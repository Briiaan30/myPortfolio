## El proyecto

Una aplicación de una sola página que permite conocer mi perfil, explorar las tecnologías con las que trabajo y consultar un caso de estudio sobre el propio portfolio.

El objetivo es ofrecer una presentación clara para quienes evalúan mi perfil profesional, acompañada de código organizado y decisiones de implementación que se pueden revisar en este repositorio.

## Funcionalidades

- **Diseño adaptable:** distribución del contenido para escritorio, tablet y móvil mediante CSS Grid, Flexbox y media queries.
- **Navegación por secciones:** menú móvil y seguimiento de la sección activa con `IntersectionObserver`.
- **Caso de estudio interactivo:** detalle del proyecto con su desafío, solución y decisiones técnicas, presentado en un diálogo nativo.
- **Accesibilidad:** enlace para saltar al contenido, foco visible, navegación por teclado y respeto por la preferencia de movimiento reducido.
- **Contacto y código:** acceso a GitHub, LinkedIn y WhatsApp, con un mensaje inicial para conversar sobre oportunidades laborales.
